# Bankers — video log (§5F)

One line per video. **Read this before every build.** Two rules come from it:

- **Never open two consecutive videos with the same hook chart type or the same hero object.**
- **Never repeat a signature composition within any five-video run.** "Signature composition" means
  the arrangement on screen, not the component: the same `CandleChart` can return, but never staged
  the same way.

The hook chart type is one of **line**, **two bars on one axis** or **candlesticks**, named in each
prompt (§5A rule 2). **Since Video 3 the hook need not be a chart** (STYLE.md §10.1, 2026-09-30): log its
construction instead, and never open two consecutive videos with the same one.
